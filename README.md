# VocabApp - IT Vocabulary Learning

VocabAppは、ITエンジニアや学習者が重要なIT用語を効率的に習得するためのSwiftUIアプリケーションです。間隔反復学習（SRS）アルゴリズムを採用しており、忘却曲線に基づいた最適なタイミングで復習を行うことができます。

## 主な機能

- **IT単語100選を内蔵**: アルゴリズム、API、ブロックチェーンなど、現代のエンジニアに必須の100単語を最初から収録。
- **効率的な学習アルゴリズム**: SM-2アルゴリズムを搭載し、あなたの定着度に合わせて次回の復習日を自動算出。
- **2つの学習モード**:
    - **クイズモード**: 英単語に対してその正確な定義（意味）を選択肢から選ぶテスト形式。
    - **フラッシュカードモード**: 表に単語、裏に意味を表示し、記憶の定着を確認。
- **単語管理**: 単語の一覧表示、検索、新しい単語の追加や既存単語の編集が可能。
- **統計表示**: 今日復習すべき単語数や、これまでに学習した単語数を一目で確認。

## 技術スタック

- **言語/フレームワーク**: Swift / SwiftUI
- **データベース**: SwiftData (永続化)
- **アーキテクチャ**: Model-View-Intent (MVI) 的なアプローチ
- **ロジック**: SM-2 Algorithm (Spaced Repetition System)

## セットアップ

1. **プロジェクトを開く**:
   `word_app.xcodeproj` をXcodeで開きます。

2. **実行する**:
   ターゲットとしてシミュレータまたは実機を選択し、`Run (Cmd + R)` を実行します。

3. **初期データ**:
   初回起動時に `initial_words.csv` から100個のIT単語が自動的に読み込まれます。

## 使い方

- **Scheduled Review**: 今日復習が必要な単語を学習します。
- **Study All Words**: 登録されているすべての単語からランダムに学習します。
- **Review Learned Only**: すでに一度でも学習したことのある単語のみを対象に復習します。
- **+ ボタン**: 自分専用の新しい単語を追加できます。

## 開発者向け

このプロジェクトは医療系単語アプリからIT単語学習アプリへとリブランディングされました。内部コードでは `context` プロパティが単語の詳細な定義を保持しており、クイズの選択肢として利用されます。
